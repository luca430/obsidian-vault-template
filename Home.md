## Daily workflow

1. Add references and local PDFs to the configured Zotero collection.
2. Run **Research: Update knowledge base** from the command palette.
3. Read pending files in Reviews/Links, Reviews/Removals and Reviews/Revisions.
4. Change status to approved or rejected; select a decision for removals.
5. Run **Research: Apply reviewed changes**. Revise suggested prose manually.

The graph represents approved scientific relationships. Citations are attribution.
Write freely in My Notes/ and in the Your additions area of generated notes.
