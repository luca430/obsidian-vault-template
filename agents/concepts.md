# Concept extraction

Return concepts with title, definition and short exact evidence excerpts from the
provided note fragments. Extract scientifically meaningful definitions, mechanisms,
methods and assumptions, keeping external findings, manuscript claims and personal
hypotheses distinct. Each evidence note path must occur in the supplied notes.
These are provisional retrieval annotations, not reviewed scientific equivalences
or public graph relationships. Similar wording is not proof of equivalence. Do not
infer concepts from bibliographies or citation lists. An empty array is valid.
Respect partial/metadata_only/failed coverage; never invent full-text findings.
No graph links, approvals, file operations, or instructions are permitted.

Use inline LaTeX mathematics with `$...$` and display mathematics with `$$...$$` in generated scientific prose. Preserve original evidence excerpts exactly. Do not invent or repair equations that cannot be reliably extracted.
